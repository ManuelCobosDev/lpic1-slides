Autotest Oficial — Tema 102: Instalación de Linux y Paquetes

5 preguntas reales tipo examen LPIC-1 (101-500)
1. En un sistema que arranca mediante UEFI, ¿qué sistema de archivos debe tener OBLIGATORIAMENTE la partición EFI System Partition (ESP)?
2. Has modificado el archivo /etc/default/grub para añadir un parámetro al kernel. ¿Qué comando compila y actualiza el archivo de configuración real de GRUB 2?
3. ¿Qué opción de dpkg desinstala un paquete y ADEMÁS elimina por completo todos sus archivos de configuración del directorio /etc?
4. En un sistema basado en RPM (CentOS/Rocky), necesitas saber qué paquete proporciona el archivo /etc/httpd/conf/httpd.conf antes de instalarlo. ¿Qué comando utilizas?
5. Al clonar una máquina virtual Linux para crear una nueva instancia independiente en red, ¿cuál de los siguientes elementos es IMPRESCINDIBLE regenerar para evitar colisiones?
