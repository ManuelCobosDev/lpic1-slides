# Diapositivas de Apoyo LPIC-1 (Recurso Didáctico de Aula)

Material didáctico e interactivo de apoyo para la preparación de la certificación **Linux Professional Institute LPIC-1** (Exámenes 101-500 y 102-500).

## Acceso Web
El contenido está publicado en GitHub Pages:
👉 **https://manuelcobosdev.github.io/lpic1-slides/**

## Atajos de Teclado y Control
- `Espacio` / `→` : Siguiente paso o diapositiva
- `←` / `Retroceso` : Diapositiva o paso anterior
- `?` : Abrir panel de ayuda y atajos
- `O` : Vista general de miniaturas (Overview)
- `N` : Panel de notas didácticas
- `F` : Pantalla completa
- `Esc` : Cerrar modales y paneles
